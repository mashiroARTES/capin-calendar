# 🐾 CAPINカレンダー

**CAPINボランティア向けシフト管理カレンダーアプリ**

ボランティアさんが「いつ・どこで・何の活動をするか」をスマホからかんたんに登録・確認できるシフト管理ツールです。

## 📱 ボランティアさん向け — 使い方ガイド

### アカウント登録・ログイン

1. アプリを開くと「ログイン」画面が表示されます
2. 初めての方は「新規登録」から名前・メールアドレス・パスワード（8文字以上）を入力して登録
3. 登録後は自動でログインされます

> ログインしなくても「ゲストとして見る」ボタンで **閲覧のみ** 可能です

---

### カレンダーの見方

画面上部のタブで表示を切り替えられます。

| タブ | 内容 |
|------|------|
| **⚡クイック** | ミニカレンダー＋選択日の詳細一覧。**デフォルト表示** |
| **月** | 月カレンダー表示。全セルスクロール対応 |
| **一覧** | 日付順のリスト表示 |
| **今日** | 今日の詳細ポップアップをすぐに開きます |

#### クイックビューの見方（デフォルト）

- **PC（横長画面）**：左側にミニカレンダー、右側に選択日の詳細が横並びで表示
- **スマートフォン**：上部約1/3にミニカレンダー、下部に選択日の詳細がスクロール表示

│ 🆘 緊急募集: 第１シェルター 🐶犬      │  ← SOSアラート

#### 常時表示される枠（人がいなくても表示）

以下の場所・活動・時間帯は人が登録していなくても常に「＋ 登録する」として表示されます：

| 場所 | 活動 | 時間帯 |
|------|------|--------|
| 第１シェルター | 🐶 犬 / 🐱 猫 | 朝・夕 |
| 第１シェルター | 📦 支援物資 | なし（時間帯指定なし） |
| 第２シェルター | 🐶 犬 / 🐱 猫 | 朝・夕 |
| パル動物病院 | 🐱 猫 | 朝・夕 |

### シフトを登録する

#### 方法①：「＋ 登録する」をタップ（クイックビューの未登録枠）

クイックビューの「＋ 登録する」をタップすると、**場所・活動内容・時間帯が事前入力** された状態でフォームが開きます。名前を確認して「登録する」を押すだけで完了です。

#### 方法②：「この日にシフトを登録」ボタン

クイックビューの **上部（日付バーの右）** または **下部** にある青いボタンをタップするとフォームが開きます。

#### 方法③：管理者パネルから代理登録

管理者は「代理登録名」欄に別のボランティアの名前を入力することで代理登録できます。

#### フォームの入力項目

| 項目 | 説明 |
|------|------|
| **日付** | 活動する日 |
| **場所** | 第１シェルター / 第２シェルター / パル動物病院 / その他 |
| **活動内容** | 🐶犬 / 🐱猫 / 🐾動物その他 / 💼事務 / 🤝折衝 / 📦支援物資 / 🚗病院搬送 / 🏠センター引き出し / 🪤捕獲 / 🏥病院受付 / ✏️その他 |
| **時間帯** | 朝 / 昼 / 夕 の3択ボタン |
| **メモ** | 時間指定など（例：10時〜）任意 |

> 同じ日に複数のシフトを登録できます

---

### 自分のシフトを編集・削除する

1. 詳細ポップアップで自分の名前チップをタップ
2. 詳細モーダルの「編集」または「削除」ボタンを使う

> 自分のシフトのみ編集・削除できます（管理者はすべて操作可能）

---

### ひとこと掲示板を書く

各日の詳細パネル内に **ひとこと掲示板** 欄があります。

- ログインしていれば誰でも書き込み・更新できます
- 1行目〜3行目それぞれに100文字まで入力できます
- 「最終更新：◯◯ さん」が表示されます
- カレンダー上にも 📌 アイコンで先頭行が表示されます

## 🛡️ 管理者向け機能

管理者アカウントでログインするとヘッダーに 🛡 アイコンが表示されます。

### 🆘 SOSマーク（人手不足アラート）設定

| 操作 | 説明 |
|------|------|
| **日付を選択** | SOSマークをつける日付 |
| **場所を選択** | 対象のシェルター・場所 |
| **活動内容を選択** | 活動種別 |
| **重要度を選択** | 🟡 募集（デフォルト）/ 🔴 緊急募集 |
| **コメント（任意）** | 「あと2名必要」など補足メッセージ |

SOSマークはクイックビューの選択日詳細パネル上部と、月ビューのセルに表示されます。

### 権限管理

- ユーザー一覧の確認
- メールアドレスを入力して管理者 ↔ ボランティアの権限変更

### 管理者専用のシフト機能

- **代理登録**：任意の名前を指定してシフト登録（アカウントに紐づかない名前でも可）
- **全シフトの編集・削除**
- **ステータス変更**：承認済み / 却下

## 🏗️ システム構成

```
CAPINカレンダー
├── フロントエンド  Vanilla JS + Tailwind CSS（CDN）  ← public/static/app.js
├── バックエンド    Hono フレームワーク（TypeScript）  ← src/index.tsx + src/routes/
├── データベース    Cloudflare D1（SQLite）
└── ホスティング   Cloudflare Pages / Workers
```

### APIエンドポイント一覧

| メソッド | パス | 説明 | 認証 |
|----------|------|------|------|
| GET | `/api/health` | ヘルスチェック | 不要 |
| POST | `/api/auth/register` | 新規ユーザー登録 | 不要 |
| POST | `/api/auth/login` | ログイン・JWT発行 | 不要 |
| GET | `/api/calendars` | 場所一覧取得 | 不要 |
| GET | `/api/shifts` | シフト一覧取得（年月・場所フィルター） | 任意 |
| POST | `/api/shifts` | シフト登録 | 要ログイン |
| PUT | `/api/shifts/:id` | シフト更新 | 要ログイン（本人 or 管理者） |
| DELETE | `/api/shifts/:id` | シフト削除 | 要ログイン（本人 or 管理者） |
| GET | `/api/day-notes` | ひとこと掲示板取得（年月指定） | 任意 |
| PUT | `/api/day-notes/:date` | ひとこと掲示板更新 | 要ログイン |
| GET | `/api/sos-badges` | SOSバッジ一覧取得（年月指定） | 任意 |
| POST | `/api/sos-badges` | SOSバッジ作成・更新 | 管理者のみ |
| DELETE | `/api/sos-badges/:id` | SOSバッジ削除 | 管理者のみ |
| GET | `/api/users` | ユーザー一覧 | 管理者のみ |
| PUT | `/api/users/:id/role` | 権限変更 | 管理者のみ |
| POST | `/api/users/promote-by-email` | メールで権限変更 | 管理者のみ |

## 🗄️ データベース構成（Cloudflare D1）

### マイグレーション一覧

| ファイル | 内容 |
|----------|------|
| `0001_initial_schema.sql` | users・calendars・shifts・sessions テーブル |
| `0002_add_animal_type.sql` | animal_type カラム追加 |
| `0003_update_shift_fields.sql` | activity_type・location_type 等追加 |
| `0004_add_day_notes.sql` | day_notes テーブル（ひとこと掲示板） |
| `0005_add_sos_badges.sql` | sos_badges テーブル（人手不足SOSマーク） |
| `0006_add_sos_urgency.sql` | sos_badges.urgency カラム追加（募集/緊急募集） |
| `0007_add_shift_override_name.sql` | shifts.override_user_name カラム追加（代理登録名） |

### テーブル一覧

#### `users` — ユーザー
| カラム | 型 | 説明 |
|--------|----|------|
| id | INTEGER | 主キー |
| name | TEXT | 表示名 |
| email | TEXT | メールアドレス（一意） |
| password_hash | TEXT | ハッシュ化パスワード |
| role | TEXT | `admin` or `volunteer` |

#### `calendars` — 場所
| カラム | 型 | 説明 |
|--------|----|------|
| id | INTEGER | 主キー |
| slug | TEXT | 識別子（例: `shelter1`） |
| name | TEXT | 表示名（例: `第１シェルター`） |
| color | TEXT | カレンダーカラー（HEX） |

**初期データ**
- 第１シェルター（`shelter1`）🔵
- 第２シェルター（`shelter2`）🟢
- パル動物病院（`animal_hospital`）🟠

#### `shifts` — シフト登録
| カラム | 型 | 説明 |
|--------|----|------|
| id | INTEGER | 主キー |
| user_id | INTEGER | 登録ユーザー |
| calendar_id | INTEGER | 場所（カレンダー） |
| shift_date | TEXT | 活動日（YYYY-MM-DD） |
| start_time | TEXT | 時間帯キー（`morning` / `afternoon` / `night`）または HH:MM |
| end_time | TEXT | 終了時刻（HH:MM、現在は未使用） |
| activity_type | TEXT | 活動種別（`dog` / `cat` / `other_animal` / `office` / `negotiation` / `supplies` / `transport` / `rescue` / `capture` / `hospital_reception` / `other_custom`） |
| activity_custom | TEXT | 活動「その他」時の任意テキスト |
| location_type | TEXT | 場所種別（カレンダーslug or `other_location`） |
| location_custom | TEXT | 場所「その他」時の任意テキスト |
| override_user_name | TEXT | 代理登録時の表示名（管理者のみ設定可） |
| status | TEXT | `pending` / `approved` / `rejected` |
| note | TEXT | メモ（時間指定など） |

#### `day_notes` — ひとこと掲示板
| カラム | 型 | 説明 |
|--------|----|------|
| note_date | TEXT | 対象日（YYYY-MM-DD、一意） |
| content | TEXT | 内容（最大3行、合計300文字以内） |
| updated_by_name | TEXT | 最終更新者の名前 |

#### `sos_badges` — 人手不足SOSマーク
| カラム | 型 | 説明 |
|--------|----|------|
| id | INTEGER | 主キー |
| badge_date | TEXT | 対象日（YYYY-MM-DD） |
| calendar_id | INTEGER | 場所（calendars.id） |
| activity_type | TEXT | 活動種別 |
| urgency | TEXT | `normal`=🟡募集 / `urgent`=🔴緊急募集 |
| message | TEXT | 補足コメント（最大50文字、任意） |
| created_by | INTEGER | 設定した管理者のuser_id |

## 🚀 開発者向け — セットアップ

### 必要なもの
- Node.js 18+
- Cloudflare アカウント
- Wrangler CLI

### ローカル開発

```bash
# リポジトリをクローン
git clone https://github.com/mashiroARTES/capin-calendar.git
cd capin-calendar

# 依存関係インストール
npm install

# DBマイグレーション（ローカル）
npm run db:migrate:local

# ビルド後、ローカルサーバー起動（ポート3000）
npm run build
npx wrangler pages dev dist --d1=capin-calendar-production --local --ip 0.0.0.0 --port 3000
```

### 本番デプロイ

```bash
# D1データベース作成（初回のみ）
npx wrangler d1 create capin-calendar-production

# wrangler.jsonc の database_id を更新後、マイグレーション適用
npm run db:migrate:prod

# ビルド＆デプロイ
npm run build
npx wrangler pages deploy dist --project-name capin-calendar
```

### 環境変数（Cloudflare Secrets）

```bash
# JWTシークレットを設定（必須）
npx wrangler pages secret put JWT_SECRET --project-name capin-calendar
```

### npm スクリプト

| コマンド | 説明 |
|----------|------|
| `npm run build` | Viteでビルド（`dist/`に出力） |
| `npm run db:migrate:local` | ローカルDBにマイグレーション適用 |
| `npm run db:migrate:prod` | 本番DBにマイグレーション適用 |
| `npm run db:seed` | テストデータ投入 |
| `npm run db:reset` | ローカルDBリセット＋再マイグレーション |
